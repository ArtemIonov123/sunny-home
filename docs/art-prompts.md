# 🎨 Все промпты для графики «Солнечного дома»

Здесь собраны промпты для всего, что нарисовано в игре: комнаты, мебель, еда, герои, одежда, зверята, магазин и карта. Каждый блок готов к копированию в GPT. Ниже каждого блока написано, куда класть картинки и что с ними дальше делает программа.

> **Как пользоваться.** Скопируйте раздел «0. Общий стиль» и пришлите его GPT первым сообщением. Потом присылайте наборы из разделов ниже, по одному.
> Новый предмет, которого здесь нет, просите по образцу похожего: имя файла, размер и правила те же, меняется только описание.

## 0. Общий стиль (присылать первым сообщением)

```
Ты рисуешь графику для детской игры в стиле Toca Boca (Toca Life World).
Стиль для ВСЕХ картинок:
- милый плоский мультяшный стиль, мягкие пастельные цвета, крупные простые формы,
  скруглённые углы, лёгкая заливка без сложных теней (максимум одна мягкая тень-полутон);
- толстый тёмно-коричневый контур (#3B2A20), одинаковой толщины на всех картинках;
- никакого текста, букв, цифр, логотипов и брендов на картинках;
- никаких персонажей Toca Boca и других чужих персонажей — только свои, оригинальные;
- предмет целиком в кадре, ничего не обрезано, вокруг небольшой отступ.
Формат: PNG. Если не сказано другое — 1024×1024, ПРОЗРАЧНЫЙ фон
(если прозрачный не получается — сплошной ярко-розовый #FF00FF без теней и градиента).
Каждый файл называй ТОЧНО так, как я пишу (латиницей, с подчёркиваниями).
Все картинки одного набора верни одним zip-архивом.
```

**Правила для всех наборов:**

| Правило | Почему |
|---|---|
| Не больше 10 картинок за раз, лучше один набор | GPT держит стиль одинаковым только внутри маленькой партии |
| Имена файлов точные | `tools/prepare_art.py` ищет файлы по имени |
| Стены и пол — только серые и бесшовные | цвет комнаты игра красит сама, игрок выбирает его в редакторе |
| Мебель — вид спереди, нижний край ровный и горизонтальный | вещь «стоит» на полу по нижней кромке |
| Окна, двери, мебель — прозрачный фон или #FF00FF | розовый фон программа сама делает прозрачным (`keyed`) |
| Две картинки одной вещи (закрыто/открыто) — одинаковый размер, положение и ракурс | программа обрезает обе одной рамкой (`sprite_pair`), иначе вещь «прыгает» |
| Мебель для интерьера — без пола и стены за ней | иначе в игре будет квадрат |

**Что делать с полученным архивом (для программиста):**
1. Распаковать в `art-src/<папка>/`. Папка указана у каждого набора.
2. Запустить `python3 tools/prepare_art.py`. Только карта — `python3 tools/prepare_art.py map`, только магазин — `python3 tools/prepare_art.py shop`.
3. Готовые картинки появятся в `assets/`. Новый ключ добавить в `ASSET_KEYS` (`src/assets.js`), определение — в `src/core/catalog.js`.
4. `git pull`, `npm run build`, тесты, отправить оба файла.

**Без программиста (через студию):** свой предмет, свою зверушку, свой район, своё здание места и свои стены/полы можно загрузить прямо в студии (раздел 11). Готовые правки отправляются игрокам кнопкой «📤 В игру».

## 9. Герои (Мила, Тим) — конструктор

Папка: `art-src/hero/`. **Это самый строгий набор.** Герой собирается из слоёв, наложенных друг на друга. Поэтому каждая часть рисуется **на холсте того же размера и в том же месте**, где она была бы у целого героя.

**Перекрашивание:** всё, что игрок перекрашивает (кожа, волосы, одежда), рисуется **светло-серым**. Контур — тёмно-коричневый. Детали, которые не перекрашиваются (глаза, румянец, пуговицы, шнурки), — цветные. Программа (`split_tint`) сама делит картинку на «серое → перекрасить» и «цветное → как есть».

> **Заменить героев можно без программиста:** студия → «Герои» (раздел 9.7). Промпты 9.1–9.5 те же, но вместо описания места к сообщению прикладывается **образец из студии**. На образце видно, куда рисовать, и вероятность, что GPT промахнётся, гораздо меньше.

### 9.6. Своя одежда без программиста: студия → «Одежда»

В студии есть вкладка **«Одежда»**. В ней новая вещь для героев делается из **одной картинки** от GPT, без частей. Студия сама:
- делит вещь на рукава, туловище и штанины, чтобы она двигалась вместе с героем;
- делает серое перекрашиваемым, а цветное и контур оставляет как есть;
- кладёт вещь в шкафчик и гардероб героя (😊 → 👕);
- отправляет её в паки и игрокам.

2. Выбрать **тип**.
3. **«📥 Образец для GPT»** — скачать картинку-образец. На ней серый герой, а голубым показано, где сидит такая вещь.

## 13. Загрузка в студии (без программиста)

| Что | Где в студии | Какую картинку просить у GPT |
|---|---|---|
| Свой предмет | «Предметы» → «＋», потом «Оживить» (полки, открывание, свет, вода, еда, одежда, прибор) | как мебель или еду: вид спереди, прозрачный фон. Для открывания нужно 2 картинки в одной рамке |
| Встроенный предмет | «Предметы» → нажать на встроенный → «Заменить картинку» (и «Заменить картинку «открыто» / «полная»») | та же вещь по промпту из разделов 2–12; у холодильника, шкафа, унитаза, миски — пара картинок (раздел 13.1) |
| Герои (тело, голова, лица, причёски, встроенная одежда) | «Герои» | по образцу из студии, раздел 9.7 |
| Своя одежда | «Одежда» → «＋ Новая вещь» | одна картинка по образцу из студии, раздел 9.6 |
| Свой зверёк | «Животные» → «＋» | 8 частей, раздел 10.1 |
| Свой район | «Карта» → «🗺️ Районы и здания» → загрузить район | `district_<id>.png`, раздел 12.2 |
| Здание своего места | «Карта» → «🏠 Свои места» → «＋ Создать новое место…» → картинка здания | `iso_<id>.png`, раздел 12.1 |
| Свои стены и полы | «Комнаты» → «Свои отделки» | серая бесшовная фактура `tex_wall_<имя>.png` / `tex_floor_<имя>.png`, 1024×1024 |
| Обложка, слайды, фон пака | «Паки» | 960×600 без текста, раздел 15 |

Промпт для своих отделок:
```
Нарисуй бесшовную фактуру для стены детской игры, 1024×1024, ТОЛЬКО оттенки светло-серого
(основной тон около #D8D8D8), без контура, без предметов, без теней от света. Края стыкуются со всех сторон.
Тема: <деревянные доски / камень / пузыри / звёздочки / джунгли-листья / кафель-соты>.
Имя файла: tex_wall_<имя>.png
```
(для пола — то же самое с `tex_floor_<имя>.png`. Цветную фактуру тоже можно загрузить, она останется как есть, но тогда игрок не сможет её перекрасить.)

### 13.1. Вещи с двумя картинками: «открыто» и «полная»

У встроенных холодильника, шкафа и унитаза есть картинка «открыто», у миски — «полная». Если заменить только обычную картинку, вторая останется старой и не совпадёт. Поэтому такие вещи заказывай **парой** и загружай обе: «Предметы» → вещь → «Заменить картинку», потом «Заменить картинку «открыто»» (у миски — «полная»). Если обе картинки одного размера и вещь на одном месте, студия совместит их сама. Проверь кнопками «Закрыто / Открыто».

```
Нарисуй новый холодильник для кухни (стиль из первого сообщения) — ДВЕ картинки одной и той же вещи.
Обе: холст 1254×1254, прозрачный фон, вид спереди, нижний край ровный,
холодильник ТОЧНО на одном месте и одного размера на обеих картинках.
1. fridge_closed.png — высокий ретро-холодильник, две дверцы закрыты, цвет <лавандовый>
2. fridge_open.png — ТОТ ЖЕ холодильник, дверцы открыты наружу, внутри 3 пустые ровные светлые полки,
   лёгкий свет внутри. Корпус не двигается — меняются только дверцы.
```
Так же:
- **шкаф** — `wardrobe_closed.png` / `wardrobe_open.png` (внутри перекладина и 2 пустые полки);
- **унитаз** — `toilet_closed.png` / `toilet_open.png` (крышка поднята);
- **миска** — `pet_bowl_empty.png` / `pet_bowl_full.png`, холст 1024×1024: та же миска, во второй — горка корма.

## 14. Частые ошибки GPT и как их поправить

| Проблема | Что написать GPT |
|---|---|
| Нарисовал белый или клетчатый фон вместо прозрачного | «Фон должен быть по-настоящему прозрачным PNG или сплошным #FF00FF» |
| Открытая и закрытая вещь разного размера | «Возьми первую картинку за основу и измени только дверцу, всё остальное оставь пиксель в пиксель» |
| Стена или пол цветные | «Только оттенки серого, без цвета» |
| Есть шов при повторении | «Сделай бесшовной: левый край должен продолжать правый, верх — низ» |
| Части героя или зверька не совпадают с целым | «Наложи часть на исходную картинку — она должна лечь точно на своё место, холст того же размера» |
| Появился текст или буквы | «Убери весь текст, буквы и цифры» |
| Стиль поплыл к концу партии | присылать меньше картинок за раз и повторять сообщение «0. Общий стиль» |
| Мебель с полом и тенью под ней | «Без пола и без тени на полу, нижний край — ровная линия» |

## 15. Паки: тематический набор и его оформление в магазине

Пак — это набор вещей, который игрок получает в магазине игры (🛒): бесплатно, за деньги или в подарок. Пак собирается в студии: «Паки» → выбрать вещи → оформить → «Опубликовать». Картинки для пака бывают двух видов:
1. **Сами вещи пака.** Это обычные предметы: мебель, еда, одежда, зверята. Их рисуют по промптам из разделов 2–12 и загружают в студию → «Предметы» → «＋».
2. **Оформление.** Обложка, слайды «что внутри» и фон страницы пака. Промпты для них — ниже.

| Картинка | Размер | Куда в студии | Что видит игрок |
|---|---|---|---|
| Фон обложки | 960×600 (16:10) | «Паки» → «🖼 Свой фон» | плитка пака в магазине, вещи пака игра ставит поверх сама |
| Обложка целиком | 960×600 (16:10) | «Паки» → «🎨 Обложка целиком» | плитка пака целиком твоя картинка |
| Слайды «что внутри» | 960×600 (16:10), до 10 штук | «Паки» → «Слайды» → «＋» | страница пака, листаются вправо-влево |
| Фон страницы пака | 1280×800 | «Паки» → «Фон страницы пака в магазине» → «🖼 Картинка-фон» | фон за всей страницей пака |

> Название пака игра пишет сама. Поэтому на картинках оформления **не должно быть текста**: так детям не нужно читать, а пак можно продавать в любой стране.

### 15.1. Придумать пак

Хороший пак — это одна тема и 5–10 вещей, которые вместе во что-то играются. Например:
- **Пижамная вечеринка:** спальный мешок, палатка из одеяла, ночник-звёздочка, подушка, попкорн, фонарик;
- **Пекарня:** печь, миксер, тесто, кекс, торт, пончик;
- **Пляж:** зонт, шезлонг, ведёрко, лопатка, надувной круг, мороженое, крабик;
- **Зоомагазин:** котёнок, клетка, домик для хомяка, аквариум, корм;
- **Праздник:** торт со свечками, шарики, подарок, колпак, гирлянда.

Промпт для вещей пака (пример — «Пижамная вечеринка», папка для своих предметов любая, загружаются в студию):
```
Нарисуй набор вещей для пака «Пижамная вечеринка» (стиль из первого сообщения).
Все вещи — в одном стиле и одной палитре (сиреневый, мятный, лимонный), вид спереди, прозрачный фон,
нижний край ровный, 1024×1024, вещь в центре.
1. pack_pj_sleeping_bag.png — спальный мешок, лежит на полу (на него ложится герой)
2. pack_pj_blanket_tent.png — палатка из одеяла на двух стульях, внутри пусто
3. pack_pj_star_lamp.png — ночник-звёздочка (включается — светит)
4. pack_pj_pillow.png — пухлая подушка
5. pack_pj_popcorn.png — ведёрко попкорна (еда)
6. pack_pj_flashlight.png — фонарик
7. pack_pj_slippers.png — тапочки-зайчики
```

> В студии каждую вещь можно «оживить»: полки, сиденье или кровать, свет, еда, одежда. В паке игрок получает её уже живой.

### 15.2. Обложка пака (плитка в магазине)

### 15.5. Как собрать пак в студии

1. «Предметы» → «＋»: загрузить вещи пака, дать им имя, при необходимости «Оживить».
2. «Паки»: отметить вещи галочками, вписать название и цену (0 — бесплатно).
3. «Обложка пака»: выбрать цвет, загрузить «🖼 Свой фон» или «🎨 Обложка целиком».
4. «Слайды "что внутри"»: «＋», можно несколько сразу. Порядок меняется стрелками ← →.
5. «Фон страницы пака в магазине»: цвет или «🖼 Картинка-фон».
6. «🚀 Опубликовать» — пак появится в магазине у всех игроков.

> Обложка и фоны пишутся в пак как картинки, поэтому лучше загружать PNG или JPG до 2–3 МБ. Студия сама уменьшит их до нужного размера.
