# Заметки для работы над проектом

- Владелец пишет по-русски; комментарии в коде и тексты в игре — по-русски.
- Графику рисует GPT по промптам. Промпты: небольшими партиями (до 10 картинок, лучше один набор), с точными именами файлов. Стены и пол — только серые фактуры; окна, двери, мебель — на прозрачном фоне (или #FF00FF).
- Исходники от GPT → `art-src/`, обработка `python3 tools/prepare_art.py` → `assets/`, новый ключ добавить в `ASSET_KEYS` (`src/assets.js`).
- После изменений: `npm run build`, затем тесты (`PLAYWRIGHT_PATH=... CHROME_PATH=... node tests/smoke.mjs`). Сборка даёт ДВА файла: `dist/sunny-home.html` (игра, без админки) и `dist/studio.html` (студия = игра + админка; флаг `__STUDIO__`, `STUDIO` в config.js). Оба коммитятся, и владельцу ВСЕГДА отправлять оба файла.
- Паки: формат `sunny-home-pack` (`core/library.js`: `makePack`, `validatePack`, `loadBuiltinPacks`); файлы из `packs/` встраиваются в обе сборки (`window.EMBEDDED_PACKS`). Студия → Админка → «Паки» скачивает файл пака. Правки встроенных предметов: `applyOverride` (catalog.js), `saveOverride`/`resetOverride` (library.js), хранятся отдельно (`loadOverrides`), в паке — поле `overrides`. Дальше: хостинг паков, магазин с родительским замком, APK (Capacitor) и оплата Google Play.
- Данные: определения в `core/catalog.js`, экземпляры в `state.items` с координатами внутри комнаты. Любое изменение — через `store.change()` (отмена и сохранение). Поиск под пальцем и отрисовка — один список `entries()`.
- Формат сохранения меняется только через `SCHEMA` + функцию в `MIGRATIONS` (`save/migrate.js`).
- Вещь — ровно в одном месте: `{room,x,y}` в доме или `{inv:true}` в шкафчике. Неизвестные определения → `state.missing` (не удаляются). Свои предметы — `core/library.js`, хранятся отдельно от дома (IndexedDB `catalog`).
- Кнопки HUD работают через `ui/tap.js` (на телефоне click после перетаскивания теряется). Не использовать `scrollIntoView` — на телефоне ломает нажатия. На повёрнутом экране оси `touch-action` меняются местами (класс `#app.rotated`).
- Дух Toca Boca: читать не нужно (иконки, звук, анимация), ничего «нельзя» (вещь падает или возвращается, без ошибок), всё отзывается на касание. Тексты — только в админке.
- Физика: `core/physics.js` — `landing()` (куда упадёт вещь), `surfaces` у мебели в `catalog.js` ([x0,x1,y] в долях картинки), `item.on = {id,s,dx}` — вещь на мебели; `syncChildren()` после любого переноса. Открывание: `openArt` у определения, `item.open`, поверхность с 4-м числом 1 — внутренняя (видна/доступна только открытой); картинки двух состояний обрезать общей рамкой (`sprite_pair` в prepare_art.py). Включение: `power` у определения (`screen` — экран с мультиком, `glow` — свет, `water` — вода), `item.lit`, `actions.togglePower()`; рисует `renderer` (свет — поверх ночи). Анимации — `render/anims.js`, звуки — `audio.js`.
- Скорость: не писать в DOM каждый кадр (только при изменении); не использовать `shadowBlur`; MAX_DPR 1.5 + автокачество (`renderer.lowerQuality`); фоны комнат — `prewarm`. Замер: сценарий с `Emulation.setCPUThrottlingRate 6` на 844×390.
- Режимы (`ui/mode.js`): игра — тянуть можно героев и мелочь (`isSmall`), мебель только нажимается; редактор — тянется вся мебель, герои скрыты. Новое место без наложений — `freeSpot()`, «по местам» — `actions.arrangeRoom()`.
- Герои (Мила, Тим) — конструктор: части в `art-src/hero/` → `build_hero()` в prepare_art.py (слои `*_t` серые — перекрашиваются, `*_f` — как есть; смещения → `src/render/heroLayout.js`, генерируется). Сборка — `render/hero.js` (`refreshHero` регистрирует картинку `hero/<id>`), данные — `core/looks.js` (`char.look`), панель — `ui/heroEditor.js`. Новая одежда/причёска: картинка по образцу body_stand/head, при сдвиге — рамка в `WEAR_FIT`. Анимация — скелет `render/rig.js` (кости, суставы `JOINTS`, позы `heroPose`, движения `rigAnims`); без отдельных частей кости вырезаются из тела (`CLIP`, малый размах `AMP`), с частями от GPT (`arm_upper_left`… в art-src/hero) — собираются из них (`PART_BONES`).
- Руки: вещь в руке — `item.held = {by}` (+ `bites`), место у ладошки — `heldSpot()` (placement.js), обновляется в `syncChildren`; дать вещь — `actions.give` (одежда `CLOTHES_TO_WEAR` надевается), укус — `actions.bite`; поднесли к герою — событие `give` из interaction; рисует `drawRig(..., held)`.
- План: 1) длинный дом ✓ 0.5.0 → 2) каталог предметов в админке + шкафчик ✓ 0.6.0 → «оживление» и поверхности ✓ 0.7.0 → ванная ✓ 0.9.0 → спальня ✓ 0.9.1 → герои-конструктор ✓ 0.10.0 → скелет ✓ 0.10.1 → 3) руки, еда, одежда ✓ 0.11.0 (позы/кулачки — после частей от GPT) → 4) мебель: сиденья, открывание, хранение → 5) приборы и рецепты → 6) магазин, гардероб, стирка → 7) APK.
