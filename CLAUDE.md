# Заметки для работы над проектом

- Владелец пишет по-русски; комментарии в коде и тексты в игре — по-русски.
- Графику рисует GPT по промптам. Промпты: небольшими партиями (до 10 картинок, лучше один набор), с точными именами файлов. Стены и пол — только серые фактуры; окна, двери, мебель — на прозрачном фоне (или #FF00FF).
- Исходники от GPT → `art-src/`, обработка `python3 tools/prepare_art.py` → `assets/`, новый ключ добавить в `ASSET_KEYS` (`src/assets.js`).
- После изменений: `npm run build`, затем тесты (`PLAYWRIGHT_PATH=... CHROME_PATH=... node tests/smoke.mjs`). Сборка даёт ДВА файла: `dist/sunny-home.html` (игра, без админки) и `dist/studio.html` (студия = игра + админка; флаг `__STUDIO__`, `STUDIO` в config.js). Оба коммитятся, и владельцу ВСЕГДА отправлять оба файла.
- Паки: формат `sunny-home-pack` (`core/library.js`: `makePack`, `validatePack`, `loadBuiltinPacks`); файлы из `packs/` встраиваются в обе сборки (`window.EMBEDDED_PACKS`). Студия → Админка → «Паки» скачивает файл пака. Правки встроенных предметов: `applyOverride` (catalog.js), `saveOverride`/`resetOverride` (library.js), хранятся отдельно (`loadOverrides`), в паке — поле `overrides`. Магазин: `store/catalog.json` + `store/packs/*.json` в этом репозитории (игра читает raw.githubusercontent.com, `core/shop.js`, `STORE_BASE`), добавить пак — из студии («Паки» → «Опубликовать», `core/publish.js`, GitHub contents API, ключ в localStorage) или `tools/store.py add <файл> --price N`; свои предметы «живые»: поля записи `surfaces`, `open {image, box}`, `power`, `tap`, `drink`, `wear`, `crop` (`cleanLiving` в library.js, `toDef` в catalog.js, редактор — «Оживить» в itemEditor.js); UI — `ui/shop.js` (родительский замок, тестовая покупка `TEST_PURCHASES`). Скачанное — `loadShopState` (IndexedDB). Дальше: APK (Capacitor) и оплата Google Play (product = `pack_<id>`).
- Доступ (`core/access.js`): встроенное можно «не выдавать» — `locked` в store/catalog.json (студия → «Животные» → галочка «Выдать игроку» → «📤 Отправить игрокам», `publishForPlayers` в publish.js), пак открывает его полем `unlock`. Подарок игрокам — пак с `gift: true` (`autoGifts` в shop.js). ПЕРЕД СБОРКОЙ — `git pull`: студия пишет store/ прямо в GitHub, а сборка встраивает store/catalog.json.
- Данные: определения в `core/catalog.js`, экземпляры в `state.items` с координатами внутри комнаты. Любое изменение — через `store.change()` (отмена и сохранение). Поиск под пальцем и отрисовка — один список `entries()`.
- Формат сохранения меняется только через `SCHEMA` + функцию в `MIGRATIONS` (`save/migrate.js`).
- Вещь — ровно в одном месте: `{room,x,y}` в доме или `{inv:true}` в шкафчике. Неизвестные определения → `state.missing` (не удаляются). Свои предметы — `core/library.js`, хранятся отдельно от дома (IndexedDB `catalog`).
- Кнопки HUD работают через `ui/tap.js` (на телефоне click после перетаскивания теряется). Не использовать `scrollIntoView` — на телефоне ломает нажатия. На повёрнутом экране оси `touch-action` меняются местами (класс `#app.rotated`).
- Дух Toca Boca: читать не нужно (иконки, звук, анимация), ничего «нельзя» (вещь падает или возвращается, без ошибок), всё отзывается на касание. Тексты — только в админке.
- Физика: `core/physics.js` — `landing()` (куда упадёт вещь), `surfaces` у мебели в `catalog.js` ([x0,x1,y] в долях картинки), `item.on = {id,s,dx}` — вещь на мебели; `syncChildren()` после любого переноса. Открывание: `openArt` у определения, `item.open`, поверхность с 4-м числом 1 — внутренняя (видна/доступна только открытой); картинки двух состояний обрезать общей рамкой (`sprite_pair` в prepare_art.py). Включение: `power` у определения (`screen` — экран с мультиком, `glow` — свет, `water` — вода по дуге: `[x,y,докуда,ширина,направление°,напор]`, `render/water.js`), `item.lit`, `actions.togglePower()`; рисует `renderer` (свет — поверх ночи). Анимации — `render/anims.js`, звуки — `audio.js`.
- Скорость: не писать в DOM каждый кадр (только при изменении); не использовать `shadowBlur`; MAX_DPR 1.5 + автокачество (`renderer.lowerQuality`); фоны комнат — `prewarm`. Замер: сценарий с `Emulation.setCPUThrottlingRate 6` на 844×390.
- Режимы (`ui/mode.js`): игра — тянуть можно героев и мелочь (`isSmall`), мебель только нажимается; редактор — тянется вся мебель, герои скрыты. Новое место без наложений — `freeSpot()`, «по местам» — `actions.arrangeRoom()`.
- Герои (Мила, Тим) — конструктор: части в `art-src/hero/` → `build_hero()` в prepare_art.py (слои `*_t` серые — перекрашиваются, `*_f` — как есть; смещения → `src/render/heroLayout.js`, генерируется). Сборка — `render/hero.js` (`refreshHero` регистрирует картинку `hero/<id>`), данные — `core/looks.js` (`char.look`), панель — `ui/heroEditor.js`. Новая одежда/причёска: картинка по образцу body_stand/head, при сдвиге — рамка в `WEAR_FIT`. Анимация — скелет `render/rig.js` (кости, суставы `JOINTS`, позы `heroPose`, движения `rigAnims`); без отдельных частей кости вырезаются из тела (`CLIP`, малый размах `AMP`), с частями от GPT (`arm_upper_left`… в art-src/hero, есть с 0.17.0) — собираются из них (`PART_BONES`), суставы — `JOINTS` (по перекрытию частей), еда ко рту — `reachMouth()` (две кости), кости из `pose.front` рисуются перед туловищем. Позы — из тех же частей: нога режется по колену (`legL`→бедро, `shinL`→голень, `KNEE_CUT`), подол ниже таза — кость `lap`; `pose.squash` сплющивает кость (сидя), `pose.lie` поворачивает героя вокруг таза, `pose.only` — рисовать лишь эти кости (под одеялом — голова). Сиденья: `seats` у определения (`[x0,x1,y,1?]`, 1 — кровать, `cover` — одеяло), `char.seat = {id,s,dx,lie}`, `c.y` тогда — высота таза (`hipDrop`, `charHitBox` в placement.js), `seatLanding`/`seatsOf` в physics.js, синхронизация — `syncChildren`.
- Животные: `render/animal.js` — один скелет (части `ANIMAL_PARTS`: body, head, headSleep, tail, legFN/FF/BN/BF; суставы `joints` в долях общего холста, `autoJoint` — по нахлёсту с туловищем), `def.animal = {parts, joints, voice}`, `setupAnimal(def)` собирает скелет и картинку целиком (def.art), позы `animalPose` (walk/carried/sleep ночью/happy), рисует `drawAnimalItem` в renderer. Животное — вещь (`small`, группа animals), `item.flip` — смотрит влево; ходьба при медленном перетаскивании — `walkStep` в interaction.js (общая с героями). Сами гуляют — `core/pets.js` (`tick`, место во время ходьбы — `override` для renderer, пришло — `store.change` без отмены; `call(id)` — бежит в комнату на экране, кнопки с мордочками — `syncPets` в hud.js). Свои — запись с полем `animal` (части data:URL, `cleanLiving`), студия — `ui/animalEditor.js` (вкладка «Животные»). Встроенные: части от GPT `art-src/animals/animal_<имя>_<часть>.png` → `build_animals()` (холст не обрезается) → assets/animals/, ключи в ASSET_KEYS + определение с `animal` в catalog.js.
- Руки: вещь в руке — `item.held = {by}` (+ `bites`), место у ладошки — `heldSpot()` (placement.js), обновляется в `syncChildren`; дать вещь — `actions.give` (одежда — поле `wear` у определения, `wearOf`; напитки — `drink`), укус — `actions.bite`; поднесли к герою — событие `give` из interaction; рисует `drawRig(..., held)`.
- Рецепты: `core/recipes.js` (встроенные `BUILTIN_RECIPES`, свои — storage `recipes`, из паков — `pack.recipes`; `findRecipe(прибор, продукты)`), готовка — `tryCook` в main.js + `actions.cook`; продукты — вещи на поверхности прибора (вложенность в один уровень: прибор может стоять на мебели). Студия → «Рецепты».
- План: 1) длинный дом ✓ 0.5.0 → 2) каталог предметов в админке + шкафчик ✓ 0.6.0 → «оживление» и поверхности ✓ 0.7.0 → ванная ✓ 0.9.0 → спальня ✓ 0.9.1 → герои-конструктор ✓ 0.10.0 → скелет ✓ 0.10.1 → 3) руки, еда, одежда ✓ 0.11.0 (кулачки и полный размах ✓ 0.17.0) → 4) мебель: сиденья, открывание, хранение → 5) приборы и рецепты ✓ 0.16.0 → 6) магазин, гардероб, стирка → магазин паков (тестовые покупки) ✓ 0.13.0 → паки из студии без программиста ✓ 0.14.0 → 7) APK.
