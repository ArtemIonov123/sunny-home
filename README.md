# ☀ Солнечный дом

2D-игра про дом в духе Toca Boca: длинный дом из комнат, который листают влево и вправо, переносят вещи и героев, перекрашивают стены и пол.

**Играть:** скачайте [`dist/sunny-home.html`](dist/sunny-home.html) и откройте в браузере (на телефоне тоже). Это один файл, все картинки внутри.

## Что нового в 0.6.1

- Лужайка с настоящей графикой: небо, трава, белый забор. Дерево, куст и грядка — предметы группы «Сад»: их можно переставлять, убирать в шкафчик и брать новые в каталоге.
- Старые сохранения получают сад на лужайке автоматически (формат сохранения 3).

## Что нового в 0.6.0

- **Шкафчик.** Каждая вещь — отдельный экземпляр и всегда лежит ровно в одном месте: в доме или в шкафчике. Убрать вещь — перетащить на 📦 слева внизу. Достать — потянуть из шкафчика в комнату или нажать.
- **Каталог** (вкладка в «Вещах»): получить новую вещь в шкафчик. Пока бесплатно — деньги появятся вместе с магазином.
- **Админка → Предметы:** свои предметы из картинок GPT — картинка (розовый фон #FF00FF убирается сам), название, группа, куда ставится, размер с предпросмотром рядом с Милой. Копия, удаление, пак для переноса. Подходят паки старой админки 0.3; её предметы переносятся автоматически.
- Удалённая комната отдаёт вещи в шкафчик. Удалённый свой предмет не стирает экземпляры — они прячутся и вернутся с паком.
- «Админка → Данные» показывает счётчик вещей: в доме, в шкафчике, спрятано.
- На телефоне кнопки срабатывают надёжно и после перетаскивания.

## Что есть с версии 0.5.0

- Дом из 6 зон: лужайка, гостиная, кухня, детская, душевая, спальня.
- Листание пальцем с инерцией, кнопки комнат внизу, стрелки ← → на клавиатуре.
- Вещи и герои переносятся между комнатами; у края экрана камера едет сама.
- Правила размещения: картина и окно — только целиком на стене, столик — на полу, дверной проём — на линии пола. Неподходящее место не сбрасывает вещь назад, а прижимает к ближайшему допустимому.
- «Отделка»: цвет стен, узор обоев, материал и цвет пола — у каждой комнаты свои.
- Админка: порядок комнат, ширина, добавить и убрать комнату, разметка стены/пола/области движения, резервная копия JSON.
- Сохранение: localStorage → запасное хранилище IndexedDB → игра без записи с предупреждением.
- Комната из версии 0.4.1 переносится в гостиную автоматически.
- Вертикальный телефон: игра поворачивается и остаётся горизонтальной.

## Как устроен код

```
src/
  main.js            запуск, кадры, сохранение
  config.js          константы
  assets.js          загрузка картинок, размеры, маски прозрачности
  core/
    catalog.js       ОПРЕДЕЛЕНИЯ предметов, героев, типов комнат
    house.js         дом = список комнат; расчёт положения комнат
    placement.js     правила размещения
    store.js         состояние, отмена
    actions.js       действия: шкафчик, перестановка комнат, отделка…
    library.js       свои предметы из админки (хранение, пак)
  world/camera.js    камера, полёт к комнате, инерция
  input/
    viewport.js      поворот экрана, пересчёт касаний
    interaction.js   тап / перетаскивание / листание, прокрутка у края
  render/
    renderer.js      отрисовка, поиск вещи под пальцем
    background.js    фон комнаты (кэшируется)
    lawn.js          временная лужайка
  save/
    storage.js       хранилища
    migrate.js       проверка и обновление формата сохранения
  ui/
    hud.js           кнопки, «Вещи», «Отделка»
    admin.js         админка
    itemEditor.js    админка → Предметы
    tap.js           надёжное нажатие на телефоне
assets/              готовые картинки (WebP)
art-src/             исходники от GPT
tools/
  prepare_art.py     исходники → готовые картинки
  build.mjs          сборка в один HTML
tests/smoke.mjs      автопроверка на 4 экранах
```

**Главное правило данных:** вещь в доме — это *экземпляр* `{id, def, room, x, y}`. Координаты — внутри своей комнаты, поэтому при перестановке комнат вещи едут вместе с ними. Положение комнат в мире не хранится, а вычисляется из порядка.

## Сборка и проверка

```bash
npm install
python3 tools/prepare_art.py   # если добавлены новые картинки в art-src/
npm run build                  # → dist/sunny-home.html
npm test                       # нужен Playwright
```

Для разработки можно открыть `index.html` через любой локальный сервер (модули не работают с `file://`) — или просто собрать.

## Графика

Стены и пол рисуются серыми, игра перекрашивает их сама. Окна, двери, плинтус и мебель — отдельные картинки на прозрачном фоне. Новые картинки кладутся в `art-src/`, затем `tools/prepare_art.py`.
