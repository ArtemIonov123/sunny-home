# ☀ Солнечный дом

2D-игра про дом в духе Toca Boca: длинный дом из комнат, который листают влево и вправо, переносят вещи и героев, перекрашивают стены и пол.

**Играть:** скачайте [`dist/sunny-home.html`](dist/sunny-home.html) и откройте в браузере (на телефоне тоже). Это один файл, все картинки внутри.

## Что нового в 0.14.0 — паки без программиста

- Студия → «Предметы» → «Оживить предмет»: что это (вещь, еда, напиток, одежда), отклик на нажатие (качается, звенит, пищит), включение (свет, экран, вода — место указывается пальцем на картинке), картинка «открыто» (совмещается с закрытой сама), полки — проводишь пальцем по картинке (на «открыто» — внутренние).
- Студия → «Паки»: ключ GitHub, «🚀 Опубликовать в магазин», «Обновить в магазине», «Убрать», «↓ В студию» (взять пак из магазина и поправить). Обложка рисуется сама.

## Что нового в 0.13.0 — магазин паков

- Каталог и паки лежат в `store/` этого репозитория, игра читает их с GitHub; без сети — копия каталога из сборки. Скачанные паки работают без интернета, их вещи — со звёздочкой «новое».
- Добавить пак в магазин: `python3 tools/store.py add pack_xxx.json --price 14.99` (обложка соберётся сама). Тестовые паки: «Цветные игрушки» (бесплатно) и «Сказочная мебель» (14,99 zł).
- Студия → «Паки»: поле «Цена», кнопка «Сбросить тестовые покупки».

## Что нового в 0.8.0 — редактор комнаты

- **Два режима, как в Toca Boca.** В игре двигаются герои и мелкие вещи (еда, игрушки, одежда, тостер, блендер); мебель стоит на месте — касание мебели открывает её (холодильник) или листает дом.
- **Редактор комнаты (🛠️).** Сверху разделы с иконками: 🛋️ мебель, 🔌 техника, 🖼️ декор, 🪟 окна и двери, 🌳 сад, 🖌️ отделка. В редакторе двигается вся мебель, герои спрятаны, чтобы не мешали. ✓ — вернуться в игру.
- **✨ «По местам».** Расставляет комнату аккуратно: вещи из стандартной расстановки — на свои места, остальная мебель — вдоль стены без наложений, мелочь — на свободные места на мебели или на полу.
- **Не в кучу.** Вещь из шкафчика по нажатию встаёт на свободное место рядом с серединой экрана, а не поверх других.
- Панель «Вещи» показывает то, что можно двигать в текущем режиме: сверху — что есть в шкафчике, ниже — «взять ещё».

## Что нового в 0.7.2 — скорость

Замер на эмуляции слабого телефона (процессор ×6 медленнее, экран 844×390), средний кадр:
листание 59–76 → 20–31 мс, перетаскивание 59 → 19 мс, рывок при входе в новую комнату 150–500 → ~15 мс.

- холст рисуется с чёткостью не выше 1.5 и непрозрачным (меньше работы при выводе кадра);
- автокачество: если телефон не успевает, чёткость снижается сама (до 3 ступеней);
- интерфейс больше не переписывает кнопки каждый кадр (это вызывало пересчёт вёрстки);
- фоны всех комнат готовятся заранее в свободное время, картинки распаковываются при загрузке;
- убраны размытые тени (shadowBlur) — на Android они очень дорогие.

## Как устроен код

```
src/
  main.js            запуск, кадры, сохранение
  config.js          константы
  assets.js          загрузка картинок, размеры, маски прозрачности
  core/
    catalog.js       ОПРЕДЕЛЕНИЯ предметов, героев, типов комнат
    house.js         дом = список комнат; расчёт положения комнат
    placement.js     правила размещения
    store.js         состояние, отмена
    actions.js       действия: шкафчик, перестановка комнат, отделка…
    library.js       свои предметы из админки (хранение, пак)
  world/camera.js    камера, полёт к комнате, инерция
  input/
    viewport.js      поворот экрана, пересчёт касаний
    interaction.js   тап / перетаскивание / листание, прокрутка у края
  render/
    renderer.js      отрисовка, поиск вещи под пальцем
    background.js    фон комнаты (кэшируется)
    lawn.js          временная лужайка
  save/
    storage.js       хранилища
    migrate.js       проверка и обновление формата сохранения
  ui/
    hud.js           кнопки, «Вещи», «Отделка»
    admin.js         админка
    itemEditor.js    админка → Предметы
    tap.js           надёжное нажатие на телефоне
assets/              готовые картинки (WebP)
art-src/             исходники от GPT
tools/
  prepare_art.py     исходники → готовые картинки
  build.mjs          сборка в один HTML
tests/smoke.mjs      автопроверка на 4 экранах
```

**Главное правило данных:** вещь в доме — это *экземпляр* `{id, def, room, x, y}`. Координаты — внутри своей комнаты, поэтому при перестановке комнат вещи едут вместе с ними. Положение комнат в мире не хранится, а вычисляется из порядка.

## Сборка и проверка

```bash
npm install
python3 tools/prepare_art.py   # если добавлены новые картинки в art-src/
npm run build                  # → dist/sunny-home.html
npm test                       # нужен Playwright
```

Для разработки можно открыть `index.html` через любой локальный сервер (модули не работают с `file://`) — или просто собрать.

## Графика

Стены и пол рисуются серыми, игра перекрашивает их сама. Окна, двери, плинтус и мебель — отдельные картинки на прозрачном фоне. Новые картинки кладутся в `art-src/`, затем `tools/prepare_art.py`.
